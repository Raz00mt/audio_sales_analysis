# Анализ оптовых продаж аудиотехники

Python-проект по анализу заказов компании «Карпов Саунд» за **март 2024 года**. Рассматриваются динамика заявок, отмены, выручка, средний чек, бренды и вклад менеджеров.

**Стек:** Python, Pandas, Matplotlib, Seaborn.  
**Анализ:** [audio_sales_analysis_portfolio.ipynb](audio_sales_analysis_portfolio.ipynb)

## Данные

Данные представлены резервными выгрузками CSV и ежедневным курсом USD в TXT.

| Источник | Поля | Содержание |
|---|---|---|
| `orders.csv` | `order_id`, `product_id`, `quantity` | Товарные позиции заказов. Дата и менеджер берутся из пути к файлу. |
| `order_status.csv` | `order_id`, `client_id`, `status` | Клиент и статус заказа: `confirmed` или `canceled`. |
| `products.csv` | `id`, `name`, `price` | Каталог товаров: название («бренд, модель»), цена в USD. Категория берётся из имени папки. |
| `usd_rate.txt` | `date`, `currency_rate`, `currency` | Ежедневный курс доллара; первая строка — данные, заголовка нет. |

**Связи таблиц:** `orders.order_id → order_status.order_id`, `orders.product_id → products.id`, дата заказа `→ usd_rate.date`.

Одна строка `orders.csv` — **товарная позиция**, поэтому количество заказов рассчитывается через число уникальных `order_id`. Выручка и AOV учитывают только подтверждённые заказы.

## Структура файлов

```text
data/
├── orders/
│   └── 2024-03-01/
│       └── Имя менеджера/
│           ├── orders.csv
│           └── order_status.csv
├── products/
│   └── Категория товара/
│       └── products.csv
└── usd_rate.txt
```

Папки с другими датами, менеджерами и категориями имеют аналогичную структуру. Исходные выгрузки не включены в этот репозиторий.

## Запуск

Установить зависимости: `pip install -U -r requirements.txt`. Разместить данные в папке `data/` рядом с ноутбуком и выполнить его ячейки по порядку.

*Проект оформлен на основе учебного бизнес-кейса; обращения подразделений в ноутбуке — сценарные формулировки аналитических задач.*
